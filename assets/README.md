# assets / gambar

Put your images here, for example `lecturer.jpg` and `banner.jpg`, then type the file names in **Tetapan** (edit mode).
Letakkan gambar anda di sini, contohnya `lecturer.jpg` dan `banner.jpg`, kemudian taip nama fail dalam **Tetapan** (mod sunting).

- Use JPG or PNG / Guna JPG atau PNG.
- Keep each image under about 500 KB / Pastikan setiap gambar di bawah lebih kurang 500 KB.
- Only upload images you have the right to use / Muat naik gambar yang anda berhak guna sahaja.
